# ONIET

Proyecto en **Godot 4.7** (Forward Plus) para las olimpiadas.

## Cómo abrirlo
1. Instalar Godot 4.7.
2. Importar la carpeta del proyecto (`project.godot`).
3. Ejecutar con F5 (escena principal: `Scenes/Menu/Menu.tscn`).

## Estructura
- `Scenes/Menu` — Menú principal, selector de niveles y opciones
- `Scenes/UI` — HUD, pausa y música
- `Scenes/Niveles` — Niveles
- `Scripts` — Scripts GDScript
- `assets` — Sprites y UI (incluye packs de reserva)
- `fonts` — Fuentes

## Créditos
Assets de terceros: Four Seasons Platformer, Pixel Adventure 1, Tiny RPG Character Asset Pack. Ver licencia de cada pack.
